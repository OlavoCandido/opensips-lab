# opensips-lab

Projeto pessoal de estudos com **OpenSIPS**, mantido nos horários vagos para aprofundar conhecimento e habilidades em **VoIP** e **SIP**.

O objetivo é evoluir na prática: cada laboratório explora um recurso ou cenário específico do OpenSIPS, do registro básico até roteamento avançado, segurança e mídia.

## Objetivos

- Entender o funcionamento interno do OpenSIPS como SIP proxy/registrar
- Praticar roteamento de chamadas, autenticação e NAT traversal
- Consolidar fundamentos do protocolo SIP na prática
- Documentar cada experimento para referência futura

## Ambiente

- **VM de laboratório** dedicada aos testes
- **OpenSIPS** como componente central
